# Checks

### UPSTREAM_REUSE-001 Exact baseline
Question: Is behavior inspected at the owner-supplied pinned repository commit?
Primary witness: Upstream lock and current checkout identity.
Counterexample: Use a latest online branch as the pinned implementation.

Counterexample: Compare similarly named functions without tracing calls.
